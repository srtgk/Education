# 二者面談 日程調整・計画表作成ツール

学校現場の二者面談の日程調整と計画表作成を効率化するための、ブラウザ完結型Webアプリケーションです。サーバー不要の静的HTMLのため、GitHub Pagesなどで簡単に公開・共有できます。

## 主な機能

- **CSVデータの読み込み**: Googleフォーム等から出力したアンケート結果（希望日時、NG日時、兄弟関係など）を自動でパースします。
- **自動割り当て**: 希望日やNG日時、校内の兄弟・姉妹関係（連番配置の配慮）を考慮して自動でスケジュールを配置します。
- **ドラッグ＆ドロップ調整**: 直感的な操作で児童の名前を別の枠へ移動したり、未配置リストへ戻すことができます。
- **一括シフト機能**: 指定したコマ以降の面談をまとめて後ろへずらすことができます。
- **A4印刷 / PDF出力対応**: 印刷時にはボタンやサイドバーが自動で非表示になり、公文書形式のきれいな表として出力・PDF保存が可能です。
- **プライバシー保護**: すべてのデータ処理はブラウザ内（ローカル）で行われるため、外部サーバーにデータが送信されることはありません。

## 使い方

1. リポジトリを公開（GitHub Pagesなど）するか、HTMLファイルをブラウザで直接開きます。
2. 「**CSVを開く**」または「**サンプル表示**」をクリックします。
3. 自動配置されたスケジュールを確認し、必要に応じてドラッグ＆ドロップで手動調整を行います。
4. 「**印刷 / PDF保存**」ボタンから印刷、またはPDFとして保存します。
